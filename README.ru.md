[English version](README.md)

## Зачем этот гайд?

Claude Code — мощный инструмент, но токены стоят денег. Одна сессия дебага может сжечь $5–20, если не понимать внутренние механизмы. Этот гайд объясняет, как Claude Code управляет контекстом, кэширует промпты и обрезает результаты — чтобы вы работали умнее, а не дороже.

## Ключевые цифры (из исходного кода)

```
ЦЕНЫ МОДЕЛЕЙ (за миллион токенов: ввод / вывод)
──────────────────────────────────────────────────
Haiku 4.5        $1 / $5       ← Простые задачи
Sonnet 4.x       $3 / $15      ← По умолчанию, баланс
Opus 4.5/4.6     $5 / $25      ← Сложные рассуждения
Opus 4/4.1       $15 / $75     ← Устаревшие
Fast Opus 4.6    $30 / $150    ← Режим скорости (6x дороже Opus!)

Чтение из кэша ~в 10 раз дешевле обычных входных токенов.

АВТО-КОМПАКТИФИКАЦИЯ
──────────────────────────────────────────────────
Порог:            context_window - 13,000 токенов
Circuit breaker:  останавливается после 3 неудач подряд
Override:         CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=<процент>

ЛИМИТЫ РЕЗУЛЬТАТОВ ИНСТРУМЕНТОВ
──────────────────────────────────────────────────
На инструмент:    50,000 символов
На токены:        100,000 токенов максимум
На сообщение:     200,000 символов (агрегат)
```
