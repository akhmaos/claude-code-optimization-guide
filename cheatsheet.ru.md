# Claude Code: Шпаргалка по оптимизации токенов

## Цены моделей (за миллион токенов)

| Модель | Ввод | Вывод | Чтение кэша | Запись кэша |
|--------|------|-------|-------------|-------------|
| **Haiku 4.5** | $1 | $5 | $0.10 | $1.25 |
| **Sonnet 4/4.5/4.6** | $3 | $15 | $0.30 | $3.75 |
| **Opus 4.5/4.6** | $5 | $25 | $0.50 | $6.25 |
| **Opus 4/4.1** | $15 | $75 | $1.50 | $18.75 |
| **Fast Opus 4.6** | $30 | $150 | $3.00 | $37.50 |

> Чтение из кэша **в 10 раз дешевле** обычного ввода. Держите сессии стабильными!

## Команды

| Команда | Что делает |
|---------|-----------|
| `/compact` | Немедленно сжать контекст |
| `/compact <подсказка>` | Сжать с фокусом на конкретной теме |
| `/cost` | Показать стоимость сессии |
| `+500k` | Установить бюджет 500K токенов (в промпте) |
| `+1m` | Установить бюджет 1M токенов |
| `use 2M tokens` | Многословный синтаксис бюджета |

## Окно контекста

| Параметр | Значение |
|----------|----------|
| Контекст по умолчанию | 200,000 токенов |
| Опт-ин 1M | Суффикс `[1m]` к имени модели |
| Порог авто-компакта | `context_window - 13,000` токенов |
| Circuit breaker | Останавливается после 3 неудач |

## Лимиты результатов инструментов

| Лимит | Значение |
|-------|----------|
| На инструмент | 50,000 символов |
| На инструмент (токены) | 100,000 токенов |
| На сообщение (агрегат) | 200,000 символов |

> Результаты, превышающие лимит, сохраняются на диск; Claude получает превью + путь к файлу.

## Переменные окружения

| Переменная | Эффект |
|------------|--------|
| `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` | Авто-компакт при N% контекста |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW` | Ограничить эффективное окно контекста |
| `DISABLE_AUTO_COMPACT` | Отключить авто-компакт (ручной `/compact` работает) |
| `DISABLE_COMPACT` | Отключить ВСЮ компактификацию |
| `CLAUDE_CODE_MAX_CONTEXT_TOKENS` | Переопределить размер окна контекста |
| `CLAUDE_CODE_DISABLE_1M_CONTEXT` | Отключить 1M контекст |
| `CLAUDE_CODE_DISABLE_THINKING` | Отключить расширенное мышление |
| `DISABLE_PROMPT_CACHING` | Отключить кэширование промптов |

## ДЕЛАЙТЕ: Экономьте токены

- **Указывайте конкретные пути** — `Read src/utils/config.ts` вместо "найди конфиг"
- **Используйте offset/limit** — `Read file.ts offset=100 limit=50` вместо чтения всего файла
- **Используйте Grep/Glob** вместо `bash find/grep` — специальные инструменты дешевле
- **Запускайте `/compact` проактивно** — не ждите авто-компакт
- **Пишите CLAUDE.md** — не объясняйте контекст проекта каждую сессию
- **Используйте субагенты** для исследований — изолирует контекст
- **Держите сессии стабильными** — переключение моделей ломает кэш
- **Ставьте бюджеты** — `+500k` предотвращает перерасход
- **Используйте Plan Mode** для сложных задач — сначала read-only
- **Будьте конкретны** — "исправь null check на строке 42 в auth.ts" > "исправь баг"

## НЕ ДЕЛАЙТЕ: Не тратьте токены

- **Не читайте огромные файлы целиком** — используйте offset/limit
- **Не используйте Bash для поиска** — Grep/Glob эффективнее
- **Не перезапускайте сессии** без необходимости — ломает кэш ($$$)
- **Не повторяйте контекст** устно — положите в CLAUDE.md
- **Не используйте Fast Opus** для простых задач — в 6 раз дороже
- **Не задавайте размытые вопросы** — ведёт к лишним уточнениям
- **Не запускайте широкие поиски** — `grep "error"` по всему репо = огромные результаты
- **Не игнорируйте `/cost`** — проверяйте расходы регулярно

## Ментальная модель

```
Ваш промпт → [Системный промпт + Инструменты + Сообщения] → API вызов
                      ↓                                         ↓
                Кэшировано (дёшево)                     Новые токены (дорого)
                      ↓                                         ↓
                TTL кэша: 5 мин                         Полная цена ввода
                (1 час для некоторых)                    + токены вывода
```

**Ключевой инсайт**: Всё, что не меняется между вызовами (системный промпт, определения инструментов) — кэшируется. Всё, что меняется (ваши сообщения, результаты инструментов) — стоит полную цену. Стабильные сессии → больше кэш-хитов → меньше денег.
