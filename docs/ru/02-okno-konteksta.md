# Управление окном контекста

## Окно контекста по умолчанию

Claude Code использует окно контекста **200,000 токенов** по умолчанию (`MODEL_CONTEXT_WINDOW_DEFAULT`).

Сумма системного промпта + определения инструментов + история + текущее сообщение + ответ должна уместиться в 200K токенов.

## Опт-ин на 1M контекст

Для сложных задач можно включить окно **1,000,000 токенов**:
- Добавьте суффикс `[1m]` к имени модели в настройках
- Claude Code отправит beta-заголовок `context-window-1m-2025-10-01`

**Компромисс**: 1M контекст дороже — больше данных на каждый вызов API. Используйте только когда действительно нужно держать много кода в памяти.

## Эффективное окно контекста

«Эффективное» окно меньше сырого лимита — Claude Code резервирует токены для вывода:

```
effective_window = context_window - min(max_output_tokens, 20,000)
```

`MAX_OUTPUT_TOKENS_FOR_SUMMARY = 20,000` — основано на p99.99 выходов компактификации.

## Переменные окружения

| Переменная | Эффект |
|------------|--------|
| `CLAUDE_CODE_MAX_CONTEXT_TOKENS` | Жёсткий override размера окна |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW` | Ограничить эффективное окно |
| `CLAUDE_CODE_DISABLE_1M_CONTEXT` | Отключить 1M контекст (HIPAA) |

### Пример: уменьшить контекст для раннего компакта

```bash
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=50000
```

## Как растёт контекст

```
Ход 1:   [Системный + Инструменты] + [Сообщение] + [Ответ]      = ~30K
Ход 2:   [Системный + Инструменты] + [История] + [Сообщение]     = ~45K
Ход 3:   ...с результатами инструментов...                        = ~70K
Ход 10:  ...разговор накапливается...                             = ~150K
Ход 15:  Авто-компакт срабатывает при ~187K (200K - 13K)          = сжато до ~50K
```

Результаты инструментов — основной вклад. Одно чтение большого файла добавляет 50K+ токенов.

## Практические советы

1. **Читайте только нужное** — используйте `offset` и `limit`
2. **Ищите прицельно** — `Grep` с конкретными паттернами
3. **Следите за контекстом** — ждите уведомления об авто-компакте
4. **Запускайте `/compact` вручную** — когда закончили с темой
