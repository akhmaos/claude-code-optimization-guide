## Когда какую модель использовать

### Haiku 4.5 — простые задачи
- Форматирование файлов, переименование
- Простой поиск и замена
- Генерация шаблонного кода
- ~$0.01-0.05 за взаимодействие

### Sonnet — выбор по умолчанию
- Код-ревью, исправление багов
- Реализация фич, рефакторинг
- ~$0.05-0.30 за взаимодействие

### Opus 4.5/4.6 — сложные рассуждения
- Архитектурный дизайн
- Сложный дебаг через несколько файлов
- Понимание незнакомых кодовых баз
- ~$0.10-0.50 за взаимодействие

### Fast Opus 4.6 — когда нужна скорость
- Та же модель Opus 4.6, но с быстрым выводом
- **В 6 раз дороже** обычного Opus 4.6
- Переключение: команда `/fast`

## Ловушка Fast Mode

Fast mode НЕ переключает на другую модель. Это тот же Opus 4.6, но за **6x цену**:

```
Обычный Opus 4.6:  $5/$25 за Mtok
Fast Opus 4.6:     $30/$150 за Mtok
```

Сессия за $2 в обычном режиме стоит **$12** в fast mode.

## Советы

1. **Начинайте с Sonnet** — переключайтесь на Opus только для сложных задач
2. **Никогда не оставляйте Fast Mode** — выключайте после срочной работы
3. **Проверяйте `/cost`** — показывает разбивку по моделям
4. **Рассмотрите Haiku** для массовых операций
