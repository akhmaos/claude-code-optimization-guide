# Руководство по CLAUDE.md

CLAUDE.md — markdown-файл в корне проекта, который Claude Code читает в начале каждой сессии. Самый мощный инструмент для сокращения повторных токенов.

## Почему CLAUDE.md экономит токены

Без CLAUDE.md вы повторяете контекст каждую сессию:
```
"Это Next.js приложение с Prisma ORM. Строгий TypeScript.
 Тесты в __tests__/. Запускать npm test. БД — PostgreSQL..."
```

50-200 токенов × десятки сессий = тысячи потерянных токенов.

С CLAUDE.md контекст загружается автоматически и **кэшируется** (в 10x дешевле ручного ввода).

## Структура

```markdown
# Название проекта

Краткое описание в одну строку.

## Технологии
- Фреймворк: Next.js 14 (App Router)
- Язык: TypeScript (strict mode)
- ORM: Prisma с PostgreSQL
- Тестирование: Jest + React Testing Library

## Команды
- `npm run dev` — dev сервер
- `npm test` — тесты
- `npm run build` — продакшн сборка
- `npx prisma migrate dev` — миграции

## Структура проекта
- `src/app/` — страницы и API роуты
- `src/lib/` — утилиты
- `src/components/` — React компоненты
- `prisma/` — схема БД и миграции

## Конвенции
- Именованные экспорты (не default)
- Обработка ошибок: Result типы, не throw
- Доступ к БД: всегда через `src/lib/db.ts`
```

## Что включать

### Всегда:
- **Стек технологий** — фреймворк, язык, ключевые библиотеки
- **Основные команды** — тесты, сборка, линтер, миграции
- **Структура проекта** — где что искать
- **Конвенции кода** — всё неочевидное

### По ситуации:
- **Архитектурные решения** — почему сделано так, а не иначе
- **Известные подводные камни** — экономит время на обнаружение

### Не включать:
- Полную документацию API (слишком много токенов)
- Полные списки файлов (Claude может исследовать)
- Часто меняющуюся информацию (устареет)

## Иерархия

```
project/
├── CLAUDE.md              ← общий контекст проекта
├── src/
│   └── CLAUDE.md          ← контекст для src/
├── packages/
│   ├── api/
│   │   └── CLAUDE.md      ← контекст API пакета
│   └── web/
│       └── CLAUDE.md      ← контекст web пакета
```

Вложенные CLAUDE.md загружаются при работе в этих директориях. Идеально для монорепо.

## Анти-паттерны

### Слишком длинный
```markdown
# Плохо: 500+ строк документации
[Вся документация API]
[Полная схема БД]
```

### Слишком расплывчатый
```markdown
# Плохо: не помогает Claude
Это веб-приложение. Использует JavaScript.
```

### Устаревший
```markdown
# Плохо: устаревшая информация → неправильные действия
База данных: MongoDB    ← давно мигрировали на PostgreSQL
```
