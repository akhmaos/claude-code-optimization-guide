# Как работают токены в Claude Code

## Что такое токен?

Токен — базовая единица текста, которую обрабатывают языковые модели. Примерно:
- **1 токен ≈ 4 символа** английского текста (консервативная оценка внутри Claude Code)
- **1 токен ≈ 2 символа** для JSON (отдельная оценка для структурированных данных)
- Типичная строка кода ≈ 10-20 токенов

Внутренняя функция `roughTokenCountEstimation()` использует 4 байта на токен для текста и 2 байта для JSON.

## Что потребляет токены?

Каждый API-вызов к Claude включает:

| Компонент | Токены | Кэшируется? |
|-----------|--------|-------------|
| **Системный промпт** | ~2,000-5,000 | Да (стабилен между вызовами) |
| **Определения инструментов** | ~10,000-30,000 | Да (40+ инструментов) |
| **История разговора** | Варьируется | Частично (cache breakpoints) |
| **Ваше сообщение** | Варьируется | Нет (новое каждый раз) |
| **Результаты инструментов** | До 100K на результат | Нет |
| **Ответ Claude** | Варьируется | Н/Д (выход) |

### Скрытая стоимость: определения инструментов

Claude Code регистрирует **40+ инструментов** (Read, Write, Edit, Bash, Grep, Glob, Agent и др.). Каждый включает: имя, описание, JSON Schema, модель разрешений. Это добавляет **10,000-30,000 токенов** к каждому вызову API. Но они **кэшируются** — полная цена только в первый раз, потом ~10x дешевле.

## Зачем оптимизировать

Типичная сессия Claude Code — 10-50 API-вызовов. Каждый отправляет полную историю + системный промпт + определения инструментов.

Без оптимизации:
- **Короткая сессия** (10 вызовов, 50K контекст): ~$0.50-2.00
- **Средняя** (30 вызовов, 150K): ~$2.00-10.00
- **Длинная** (50+ вызовов, с компактификацией): ~$5.00-25.00

С оптимизацией:
- **Короткая**: ~$0.10-0.50
- **Средняя**: ~$0.50-3.00
- **Длинная**: ~$2.00-8.00

Разница **в 3-5 раз** — и она накапливается.
