# Авто-компактификация: глубокое погружение

Авто-компактификация — механизм Claude Code для удержания разговора в пределах окна контекста.

## Когда срабатывает авто-компакт?

```
порог = эффективное_окно - 13,000 токенов
```

Для окна 200K по умолчанию:
```
эффективное = 200,000 - 20,000 = 180,000
порог = 180,000 - 13,000 = 167,000 токенов
```

**Авто-компакт срабатывает при превышении ~167K токенов.**

### Override порога

```bash
# Срабатывать при 50% контекста
export CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=50
```

## Что происходит при компактификации

1. **Session memory compaction** — фоновый агент извлекает ключевую информацию
2. Если недостаточно — **традиционная компактификация** суммирует разговор
3. Claude получает summary + недавние сообщения как новый контекст
4. Cache breakpoints сбрасываются

### Session Memory

Фоновый агент:
- Извлекает ключевые решения и находки из разговора
- Сохраняет пары tool_use/tool_result (иначе ошибки API)
- Конфиг: срабатывает после 10K токенов и 5+ текстовых блоков
- Максимум: 40K токенов памяти сессии

### Традиционная компактификация

- Claude суммирует разговор, сохраняя критический контекст
- Summary ограничен 20K токенами (p99.99)
- Сжатый разговор заменяет оригинальные сообщения

## Circuit breaker

После **3 неудачных попыток подряд** Claude Code перестаёт пробовать:

```
MAX_CONSECUTIVE_AUTOCOMPACT_FAILURES = 3
```

Предотвращает трату API-вызовов на неисправимые ситуации.

## Microcompact: инлайн-обрезка

Отдельно от авто-компактификации, **microcompact** обрезает старые результаты инструментов:

- **По времени**: старые результаты очищаются при паузах
- **Кэшированный MC**: использует cache editing API без ломания кэша
- Очищенные результаты показывают: `[Old tool result content cleared]`

**Инструменты, подлежащие обрезке**: FileRead, FileWrite, FileEdit, Shell (Bash), Grep, Glob, WebSearch, WebFetch.

## Отключение компактификации

| Переменная | Эффект |
|------------|--------|
| `DISABLE_AUTO_COMPACT` | Только авто (ручной `/compact` работает) |
| `DISABLE_COMPACT` | ВСЯ компактификация |

**Внимание**: отключение рискует ошибками API при переполнении контекста.

## Лучшие практики

1. **Запускайте `/compact` проактивно** при смене темы
2. **Используйте `/compact <подсказка>`** — направьте, что сохранить
3. **При повторных компактификациях** — разбейте задачу на подзадачи
4. **Используйте субагенты** для исследований — у них своё окно контекста
