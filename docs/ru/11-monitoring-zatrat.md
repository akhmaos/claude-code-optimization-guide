# Мониторинг затрат

## Команда `/cost`

Запускайте `/cost` в любое время для просмотра расходов сессии:
- Общая стоимость в USD
- Разбивка токенов (ввод, вывод, чтение кэша, запись кэша)
- Стоимость по моделям
- Количество API-вызовов

**Совет**: запускайте `/cost` каждые 10-15 минут в длинных сессиях.

## Бюджеты токенов

### Краткий синтаксис
```
Исправь баг в auth.ts +500k          ← бюджет 500K
Рефакторинг API +1m                  ← бюджет 1M
Полный code review +2.5m             ← бюджет 2.5M
```

`+Nk` / `+Nm` работает в **начале или конце** сообщения.

### Многословный синтаксис
```
Use 500k tokens to fix the auth bug
Spend 2M tokens on the refactor
```

### Как работают бюджеты

- Claude Code отслеживает кумулятивное потребление токенов
- На процентных отметках показывается прогресс
- При достижении бюджета задача завершается

### Рекомендации по бюджетам

| Тип задачи | Рекомендуемый бюджет |
|------------|---------------------|
| Простой баг-фикс | `+200k` - `+500k` |
| Реализация фичи | `+500k` - `+1m` |
| Большой рефакторинг | `+1m` - `+3m` |
| Полный ревью кодовой базы | `+2m` - `+5m` |

## Формулы расчёта стоимости

Из исходного кода:

```
стоимость = (input_tokens / 1M) × input_price
          + (output_tokens / 1M) × output_price
          + (cache_read_tokens / 1M) × cache_read_price
          + (cache_creation_tokens / 1M) × cache_write_price
          + web_search_requests × $0.01
```

### Быстрая прикидка

Для **Opus 4.6** ($5/$25):
- 100K input = $0.50
- 100K output = $2.50
- 100K cache read = $0.05 (в 10x дешевле!)

Для **Sonnet** ($3/$15):
- 100K input = $0.30
- 100K output = $1.50
- 100K cache read = $0.03

## Тревожные сигналы

Вы тратите токены впустую, если:
- `/cost` показывает >$5 для простой задачи
- Видите повторные уведомления об авто-компакте
- Низкий процент чтения кэша (ломаете кэш)
- Очень высокие output-токены (расширенное мышление на простых задачах)
