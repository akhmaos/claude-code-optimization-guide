# Кэширование промптов

Кэширование — самый значимый механизм экономии в Claude Code. Повторяющийся контент становится **~в 10 раз дешевле**.

## Как работает

API кэширует контент, идентичный между вызовами:

```
Вызов 1: [Сист. промпт] + [Инструменты] + [Сообщения]
           ↑ кэш              ↑ кэш         ↑ полная цена

Вызов 2: [Сист. промпт] + [Инструменты] + [Сообщения + новое]
           ↑ HIT 💰          ↑ HIT 💰       ↑ полная цена
```

## Цена кэш-хитов

| Модель | Ввод | Чтение кэша | Экономия |
|--------|------|-------------|----------|
| Sonnet | $3/Mtok | $0.30/Mtok | 90% |
| Opus 4.6 | $5/Mtok | $0.50/Mtok | 90% |
| Opus 4/4.1 | $15/Mtok | $1.50/Mtok | 90% |

## TTL кэша

- **По умолчанию**: 5 минут (эфемерный)
- **Расширенный**: 1 час для некоторых конфигураций

Пауза больше 5 минут → кэш истекает → полная цена.

## Что ломает кэш

| Действие | Ломает кэш? |
|----------|-------------|
| Отправка нового сообщения | Нет |
| Переключение модели | **Да** |
| Изменение effort level | **Да** |
| Переключение fast mode | **Да** |
| Добавление/удаление MCP инструментов | **Да** |
| Запуск `/compact` | **Да** (ожидаемо) |
| 5+ минут бездействия | **Да** (TTL) |

## Практический эффект

**30-ходовая сессия с Opus 4.6, системный промпт + инструменты = 20K токенов:**

Без кэша: 20K × 30 × $5/Mtok = **$3.00**
С кэшем: $0.10 + 20K × 29 × $0.50/Mtok = **$0.39**

**Экономия: $2.61 (87%)**

## Советы по максимизации кэш-хитов

1. **Не перезапускайте сессии** без необходимости
2. **Не переключайте модели** среди сессии
3. **Не включайте/выключайте fast mode** без нужды
4. **Работайте пакетами** — долгие паузы (>5 мин) = истечение TTL
5. **Используйте `/compact` осознанно** — он ломает кэш, но освобождает контекст
